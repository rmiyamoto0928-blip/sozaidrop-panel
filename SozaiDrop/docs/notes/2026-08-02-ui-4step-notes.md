# SozaiDrop UI改修（4段絞り込み＋縦リスト）— 引き継ぎメモ

作成: 2026-08-02 ／ この1枚を読めば、会話履歴が無くても続きから再開できる。

## 何をやっている改修か（作業契約）

- **目的**: SEとBGMが大量に混ざった一覧から、目的の素材へすぐ辿り着けるようにする
- **成果物**: 絞り込みを4段構成にする
  1. ① 種類（すべて／効果音／BGM）
  2. ② 場所（プロジェクト内／PCフォルダ）
  3. ③ フォルダをプルダウンで選択（件数つき・下位は `└` でインデント・件数は①に連動）
  4. ④ 中身を**縦1列のリスト**で表示
  ＋ PCフォルダに素材を足したら「⟳ 更新」1クリックで読み直し、増減件数を表示
- **制約**: 既存機能（クリック挿入・D&D・ホバー再生・☑モード・一括挿入・zip書き出し「送る」・★よく使う・タグ・🏷自動・NFC照合）を壊さない。ES5風の `var` ベースを維持。設定はファイル保存を維持
- **触らない**: `jsx/`（ExtendScript）・`js/autotag.js`・他パネル

### 6. デバウンス

検索欄 `#search` の `input` は **120ms**（`SEARCH_DEBOUNCE_MS = 120`）待ってから `filter.search` に反映し `render()` する。
連続入力ではタイマーが張り直される。テストは `fire(input)` のあと **150ms以上**待つこと（`filter.search` は打鍵直後はまだ前の値）。
検索以外（①②③のクリック・`⟳ 更新`）は従来どおり即時。

### 7. 本体側で確認して**変更しなかった**もの

- 挿入先トラック（指摘14）: `trackFor()` は 効果音→`trackPrefs.se`（既定`'3'`）／BGM→`trackPrefs.bgm`（既定`'4'`）を返し、`sdInsertAudioAtHeads(path, pathN, aSpec, overwrite)` の第3引数に渡る。一括は「全部BGMのときだけ `trackPrefs.bgm`、1つでも効果音が混ざれば `trackPrefs.se`」。`jsx/hostscript.jsx` の `sdResolveAudioTrackForStarts` は `parseInt(aSpec,10)-1` を索引にするので **A3=`'3'` で正しい**。ロジックに誤りは無かったため変更なし。

## 計画からの逸脱

- 指摘11は `probeDurations()` だけでなく `saveTags()`（🏷から種別を手動指定した直後）でも `buildFolderSelect(true)` を呼ぶようにした。理由：種別の手動指定も①の内訳を変えるので、同じ「③の件数が古いまま」の不具合が残ってしまうため。
- 指摘10で③のルート表示名を出す `rootLabel()` を、④のグループ見出し（`groupLabel()`）にも使った。理由：見出しは表示名、キーはフルパスと分ける必要があり、両方で同じ見分け方をしないと「見出しは同名なのに別グループ」に見えるため。
